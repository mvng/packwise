## 2024-05-13 - Replace `isHovered` with `group-hover` and `focus-within` for Action Button Accessibility
**Learning:** Using React state (e.g. `isHovered` triggered by `onMouseEnter` and `onMouseLeave`) to conditionally render or control opacity of action buttons creates a significant accessibility barrier. Keyboard users cannot trigger these mouse events, leaving the buttons unreachable via keyboard `Tab` navigation.
**Action:** Always replace state-based hover reveals with CSS-based `group-hover` and `focus-within` utilities (e.g., `opacity-0 group-hover:opacity-100 focus-within:opacity-100`). This ensures buttons remain hidden by default but automatically appear and become interactive when a user navigates to them using a keyboard. Ensure all icon-only buttons include descriptive `aria-label`s.
