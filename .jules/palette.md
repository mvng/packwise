## 2024-05-22 - Dashboard Trip Cards Keyboard Accessibility
**Learning:** In the dashboard view, the trip cards display their quick action buttons (Edit/Delete) dynamically on `group-hover`. However, this was completely inaccessible to keyboard users tabbing through the interface, as the buttons received focus but remained invisible. Tailwind's `group-focus-within` is the correct solution for this pattern instead of `group-focus-visible`. Also, during Playwright verification of authenticated routes like `/dashboard`, the server will redirect to `/login` if unauthenticated, requiring a workaround like testing isolated components or static HTML for pure CSS visual verifications.
**Action:** When implementing hidden hover actions on parent containers, always pair `group-hover:opacity-100` with `group-focus-within:opacity-100` to ensure keyboard navigation visibility. When verifying authenticated routes, use isolated static tests if session injection is complex.
