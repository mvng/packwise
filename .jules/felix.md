## 2025-02-28 - Missing Authorization in Server Actions
**Learning:** Next.js Server Actions execute on the server and are directly callable by the client. Simply checking `getUserId()` to confirm the user is logged in is not enough to secure database updates. If the query does not scope the modification to the user's ID or verify ownership of related entities (like checking if the DayPlan belongs to a Trip owned by the user), it introduces a critical IDOR vulnerability where any logged-in user can maliciously modify any record.
**Action:** Always implement robust authorization checks in Server Actions. When updating records, explicitly verify ownership by querying related entities or including the `userId` in the `where` clause of the update query to prevent unauthorized access.
